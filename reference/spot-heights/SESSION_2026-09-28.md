## Lessons recorded in READING_GUIDE.md
- `[media removed: request limit]` in a reader's history is context eviction, not a load failure. Five readers wrongly withdrew genuine work before this was understood; the overlap checker proved every withdrawn file genuine. Readers now write an anchor per crop on opening; a crop with no anchor is the only failure signal.
- Marker sheets (boxes at recorded pixels) catch 2–12 px position errors; matching digits in one figure are the same digit; the `sheet` join detector misses weak joins and reports hatching.
