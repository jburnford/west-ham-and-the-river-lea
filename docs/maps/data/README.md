# Vector layers for the historic maps page

Copied unchanged on 28 September 2026 from `jburnford/london_industry_map` (`docs/data/`, commit 543f7de of 25 September 2026), which derives from the author's GIS for *West Ham and the River Lea* and its swipe map. All files are WGS84 GeoJSON with coordinates rounded to six decimals.

| File | Content | Credit |
|---|---|---|
| Industry_1865-75.geojson, Industry_1893-95.geojson | Industrial sites digitised from the Ordnance Survey first series and 1890s revision, with type, products and dates | Jim Clifford with Steven Langlois and Anne Riitta Janhunen |
| Water_First_Series.geojson, Water_1895.geojson | Watercourses and water bodies for the two OS generations | as above |
| Docks.geojson | Docks with build and end years and flags for each OS generation | as above |
| Lower_River_Lea.geojson | The lower Lea channels | as above |
| Rail_1870.geojson, Rail_1895.geojson | Railways filtered from OpenHistoricalMap exports (rail, tram, light rail) | OpenHistoricalMap contributors |
| WestHam_1911.geojson | County Borough of West Ham boundary, 1911 | GB Historical GIS / Vision of Britain derived, as supplied in the author's GIS |
| LCC_Border.geojson | London County Council boundary | as above |

The data archive citation (Zenodo) is still a placeholder in the source repository; add the DOI here when it exists. Industrial polygons describe sites, not building footprints.
